# 已知限制

- QoL 主路径要求本地日志中已经存在有效桥接记录。本版本的桥接设置只读检查，不会安装、修复、卸载或回退模组。
- 正式支持的精确适配目标为 QoL Lock 4.0.5 hotfix，对应 GameBanana 更新 461898；版本文字、静态适配或握手本身不等于真实名单采集成功。
- Steam 备用默认关闭，真实 Steam／DLL 组合和实战名单尚未验收。候选须人工确认；缺项和未知身份不会伪装成完整数据。
- Statlocker 自动补抓的真实 API 尚未接通。等待任务、界面入口和网页跳转不表示已完成补抓。
- 外部历史服务可能未收录全部比赛，可能限流或无法访问。范围查询完成不保证历史完整，真实缺失值保留未知。
- 更新下载的 SHA-256 校验只证明与发布元数据一致，不代表代码签名、独立安全审计或反作弊认可。
- 单文件模式支持原位置更新与回滚，明确阻止“更新到其他位置”。不要手动搬动运行缓存来绕过这一限制。
- 原位置更新／回滚协议已验证，但尚未实测通过真实 GitHub 网络完成整套更新安装点击流程。
- 本版关闭窗口会退出程序及其拥有的采集进程；关闭到托盘功能尚未包含。
- 未进行游戏实战、真实 Steam 完整名单或游戏 FPS 验收；本地合成数据和空闲表现不能代表所有硬件或实战性能。
- 图形界面需要已安装的 Microsoft Edge WebView2 Runtime。资料库升级后，旧版本可能无法直接读取；恢复前使用升级前的完整资料备份。

这些限制不妨碍使用已有有效日志的主采集路径，或查询、编辑已保存的本地资料。发现来源异常时，以界面的具体状态为准。
