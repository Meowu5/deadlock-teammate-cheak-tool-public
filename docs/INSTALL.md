# 启动、校验与更新

## 首次使用

下载 **[Deadlock-Recorder-Windows-x64.exe](https://github.com/Meowu5/deadlock-teammate-cheak-tool-public/releases/latest/download/Deadlock-Recorder-Windows-x64.exe)**。该 EXE 内含应用组件，首次运行校验后准备到当前用户的私有运行缓存，并统一启动界面和采集功能。运行缓存与个人资料目录分开。

图形界面需要已有的 Microsoft Edge WebView2 Runtime；缺少时使用 [Microsoft 官方下载入口](https://developer.microsoft.com/microsoft-edge/webview2/) 按其说明安装。本软件不会自动安装该浏览器运行时。

## 校验下载

同一 Release 的 `SHA256SUMS.txt` 列出文件名与 SHA-256。在下载目录打开 PowerShell，核对主 EXE：

```powershell
Get-FileHash -LiteralPath '.\Deadlock-Recorder-Windows-x64.exe' -Algorithm SHA256
Get-Content -LiteralPath '.\SHA256SUMS.txt'
```

按文件名找到主下载 EXE，核对其 64 位十六进制哈希。不同则停止使用并重新下载。SHA-256 用于核对完整性，不等同于发布者数字签名或反作弊认证。

双击下载的 EXE。首次启动请明确选择全新资料目录或已有资料目录，检查当前账号及来源状态。如果提示资料不兼容、文件占用或需要升级，先关闭旧程序并备份整个资料目录，再按界面说明处理。

同页的 `Deadlock-Windows-x64.zip` 是应用自动更新的技术资产。GitHub 自动生成的 Source code 包只包含本下载仓库文档，不能运行程序。

设置中的资料目录才是当前使用位置。不要把整个程序目录误当成资料备份，也不要删除 SQLite 的 WAL、SHM 或事务文件来跳过错误。

## 采集前提

采集器读取你选择的本地 `console.log`。游戏需产生相应日志；若需要日志输出，可按游戏和模组当前说明配置 `-condebug`。本工具不会自动替你修改游戏启动参数。

本局名单还需要日志中存在有效 QoL 桥接记录。支持的适配目标为 QoL Lock 4.0.5 hotfix（[模组页面](https://gamebanana.com/mods/650634)、[对应更新](https://gamebanana.com/updates/461898)）。设置页只检查兼容性和来源状态，不安装桥接。没有桥接或没有有效名单时，保留“等待”或“不完整”状态属于正常降级；请勿把此状态当成零名玩家的完整结果。

## 更新与保留资料

**单文件模式只支持在当前运行位置更新及回滚，“更新到其他位置”不可用。** 更新后再次双击原来的主 EXE，会使用已更新的运行组件。需要回滚时按程序提供的恢复说明操作；程序版本回滚不等于恢复个人资料备份。

本版已验证原位置更新／回滚协议与旧 EXE 不覆盖新版缓存；尚未实测通过真实 GitHub 网络完成整套更新安装点击流程。

手动更新时，从新 Release 下载主 EXE 并重新校验，关闭旧程序、备份资料后按该版本说明启动，核对保留的资料目录。不要混合复制或删除运行组件。

软件更新卡片中，检查、下载校验、安装重启是独立操作。只有界面明确报告安装完成才算完成；“已下载”“已暂存”或“正在重启”不表示更新成功。没有正式版本、网络失败、限流、校验失败或安装条件不满足时，按显示的原因处理，也可使用上面的手动更新流程。

不要让旧版本直接打开已经迁移的新资料库。需要恢复旧版本时，使用升级前备份，并确认资料路径。

## 卸载

先正常退出软件。下载的 EXE、运行缓存和个人资料目录用途不同；删除下载文件不等于删除已保存资料。清理时按程序显示的位置核对，不要在程序运行或更新过程中清理组件、更新备份或事务文件。本工具不承担 QoL 模组或游戏文件的卸载、修复。
